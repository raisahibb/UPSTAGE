# Custom Class Naming Rule

Agar custom CSS classes banani padein, unke naam simple aur thode natural Hinglish/desi rakho.

Examples:
- badaDaaba
- leftDabba
- rightDabba
- chhotaDabba
- loginBox
- formBox
- mainBox
- titleBox
- btnBox

Do NOT use unnecessarily professional/AI-looking names such as:
- authentication-container
- user-authentication-wrapper
- dashboard-statistics-container
- interview-session-content-wrapper

IMPORTANT:
- Normal Tailwind utility classes ko unnecessarily custom class mein convert mat karo.
- Variables aur functions ko normal programming naming mein hi rakho (e.g., `userName`, `userEmail`, `interviewScore`, `handleLogin`, `handleSubmit`).
- Sirf custom CSS class names ko simple/natural Hinglish style mein rakho.
- Class names technically valid hone chahiye aur consistent naming follow karni hai.
